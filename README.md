# TripVane website

The official product, support, and privacy website for TripVane.

This is a dependency-free static site intended for GitHub Pages deployment from the `main` branch at the repository root. It contains no analytics, cookies, advertising scripts, or external runtime dependencies.

## Structure

- `index.html` — product homepage
- `privacy.html` — privacy policy
- `support.html` — support and FAQ
- `styles.css` — responsive light/dark presentation
- `assets/` — TripVane icon and App Store screenshots
